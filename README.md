# Yaka

**The only payment companion you would ever need.**

Yaka is a chat-native, multi-agent control plane for payments. Instead of jumping between dashboards, docs, and support tickets, you talk to Yaka — a dispatcher agent routes your request to specialist expert agents, which pull live data straight from connected payment services (starting with Razorpay via MCP), while an evaluator agent checks every response for loops, drift, and security issues before it ever reaches you.

Every state-changing action is idempotent. Every tool call is logged and observable. And when a transaction gets stuck — queued, pending, waiting on a bank — Yaka doesn't go quiet. It picks the same conversation back up the moment it resolves.

Named after **Yacatecuhtli**, the Aztec god of merchants — guide of safe passage, guarantor of fair trade between strangers. Yaka does the same job, just for your money instead of a caravan.

---

## Why Yaka exists

Payment infrastructure is fragmented, opaque, and slow to explain itself. When something breaks — a payout held, a settlement delayed, a UPI transaction failing — the answer is usually buried across six different dashboards, and by the time you find it, the damage to trust (and cash flow) is already done.

Yaka is built to close that gap: one conversation, connected to everything, that can actually tell you what's happening and why — fast enough to matter.
